Simulador de Préstamo Bancario

Este es un simulador de préstamos bancarios que permite calcular las cuotas mensuales de un préstamo según el monto, tasa de interés y plazo en meses. También ofrece diferentes tipos de amortización y mantiene un historial de simulaciones.

Tecnologías Utilizadas

HTML

CSS (Diseño responsivo y centrado)

JavaScript (Cálculo de amortización y lógica del simulador)

Características

📌 Formulario interactivo para ingresar datos del préstamo.

💰 Cálculo automático de cuotas según la tasa de interés y el plazo.

🔄 Soporte para diferentes tipos de amortización (ej. Francés).

📜 Historial de simulaciones.

📊 Tabla de amortización detallada.

🎨 Diseño responsivo y centrado en la pantalla.
